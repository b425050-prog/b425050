## ▶️ Quick Start

Open a terminal in the `LAB 5` folder, then compile and run any exercise:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic L5P1.cpp -o L5P1
./L5P1
```

On Windows PowerShell, run the executable with `.\L5P1.exe`. Replace `P1` with
the required problem number through `P10`.
